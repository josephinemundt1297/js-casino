# Vanilla JS Casino

A logic-driven browser game built to demonstrate core **JavaScript** fundamentals, including state management, event handling, and dynamic probability logic. This project focuses on a functional gameplay loop without the overhead of external frameworks.

## 🚀 Features
* **Dynamic Game Logic**: Real-time calculation of game outcomes and player balances.
* **Event-Driven Interaction**: Uses JavaScript event listeners to handle player inputs and bets.
* **State Management**: Tracks wins, losses, and total currency during the session.

## 🛠️ Tech Stack
* **JavaScript (ES6)**: Core game engine and DOM manipulation.
* **HTML5**: Semantic structure for the gaming interface.
